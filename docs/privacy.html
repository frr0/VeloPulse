This page covers only the website you are reading

This policy describes the VeloPulse product website (the pages you are reading now: the main page, this policy and the terms of service). It does not describe the VeloPulse app, which has a policy of its own: see below.

This website

The product website is static: HTML and CSS pages with a small amount of JavaScript for the menu on phones and for the year in the footer. The site uses no cookies, collects no browsing data, has no analytics tools, has no contact forms and loads no fonts, scripts or images from other sites: every resource (style sheets, scripts, screenshots) is part of the site itself. The only links to the outside are the app download buttons and the link to the source code, which both point to GitHub.

Server logs

This site is published with GitHub Pages: GitHub is the host. Visits to the site (for example the IP address and the page requested) are handled by GitHub under its own rules, described in the GitHub privacy statement. VeloPulse has no access to these logs and does not collect them.

The VeloPulse app

The VeloPulse app, when you use it in the browser or installed on your device, handles data differently from this site: it reads the Bluetooth sensors on your trainer, talks to Intervals.icu with the API key you enter yourself, and saves the settings locally on the device. The app has a privacy policy of its own, which you find inside it, on the "privacy.html" page: this page of the product website does not replace it and does not contradict it.

No accounts on this website

This site asks for no registration and has no accounts: there is nothing to delete here, because we collect nothing.
